## Course Syllabus

This mini-course provided a hands-on introduction to Biopython, a powerful toolkit for computational molecular biology. Participants learned how to efficiently handle biological sequences, interact with major online biological databases like NCBI using Entrez, and perform sequence similarity searches with BLAST. The course emphasized practical application through coding exercises, culminated in a project that integrates these core functionalities.
Here's a brief overview of what each day of the mini-course covered:    

**Day 1: Getting Started with Biopython & Sequence Handling (`Bio.Seq` and `Bio.SeqIO`)**  
We learned how to set up the Biopython environment. This day focused on the fundamental `Bio.Seq` module, where we learned how to create, manipulate, and analyze individual biological sequences (DNA, RNA, and protein). We covered operations like transcription, translation, reverse complementation, and basic sequence properties. We then dived into `Bio.SeqIO`, a cornerstone for working with sequence files. We learned how to read and write sequences in various common formats (FASTA, GenBank, FASTQ) from single-entry and multi-entry files, preparing you to handle real-world biological data.   

**Day 2: Accessing Online Databases with Entrez (`Bio.Entrez`)**  
Day 2 was all about connecting your Python scripts to the vast biological information available online. We explores `Bio.Entrez`, Biopython's interface to NCBI's Entrez system. We learned how to search major databases like PubMed (for literature), GenBank (for nucleotide sequences), and Protein (for protein sequences). We covered the process of retrieving detailed records and downloading sequences directly into your Python environment. This skill is crucial for gathering the necessary data for any bioinformatics project.    

**Day 3: Sequence Similarity Search with BLAST (`Bio.Blast.NCBIWWW` and `Bio.Blast.NCBIXML`)**   
This day focused on one of the most widely used tools in bioinformatics: BLAST. We concentrated on performing online BLAST searches using `Bio.Blast.NCBIWWW` and XML file accession using `Bio.Blast.NCBIXML`. We learned how to submit query sequences (nucleotide or protein) to NCBI's web service, specify search parameters (like E-value and database), and parse the XML output to extract meaningful results such as hit titles, accession numbers, E-values, and alignment details. 

**Day 4: Project Work: Integrating Biopython Tools**    
On our final day, we testedd new skills with a hands-on project. We worked on challenges that required to integrate `Bio.Entrez`, `Bio.SeqIO`, and `Bio.Blast`. These projects was designed to simulate (small-scale) real-world bioinformatics scenarios, such as annotating an unknown gene, comparing protein families across species, or batch-processing sequence identification. This day was about applying your knowledge to solve biological questions programmatically and reinforcing your understanding of Biopython's capabilities.
